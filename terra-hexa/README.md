# 테라 헥사 (Terra Hexa)

헥스 타일 위에서 도시를 세우고, 땅을 개발하고, 연구하고, 이웃 세력과 경쟁하는 **입문용 4X 턴제 전략 게임**이에요.
「문명 6」 같은 본격적인 4X 게임을 처음 배우는 사람이 핵심 개념을 손에 익힐 수 있도록 만들었어요.
(특정 게임의 복제가 아니라, 같은 장르의 규칙을 추린 오리지널 게임이에요.)

## 실행

설치나 빌드가 필요 없어요. `index.html`을 브라우저로 열면 바로 시작돼요. PC와 모바일 모두 지원해요.

## 배울 수 있는 개념

- 도시 자리 고르기 (물가 = 주거 공간), 시민이 타일에서 일하는 구조
- 건설자(3회 소모)로 농장·광산·목장 짓기, 보너스·사치·전략 자원
- 지구를 타일에 직접 놓고 **인접 보너스** 받기 (학문 지구는 산 옆!)
- 기술 트리와 **영감**(특정 행동으로 연구 40% 단축)
- 문화로 국경 확장과 정책 채택
- 한 타일 한 유닛, 지형 방어, 원거리로 깎고 근접으로 점령
- 약탈자 야영지, 유적, 외교(전쟁·평화)
- 과학 / 정복 / 점수 승리

게임 안의 **길잡이**가 한 단계씩 안내하고, 도움말의 "다음 단계" 탭에 본격적인 4X 게임으로 넘어갈 때 달라지는 점을 정리해 뒀어요.

## 조작

| 입력 | 동작 |
| --- | --- |
| 클릭 / 탭 | 유닛·도시 선택, 선택한 유닛에게 이동·공격 명령 |
| 우클릭 / 길게 누르기 | 무조건 이동·공격 명령 |
| 드래그, 휠 / 두 손가락 | 지도 이동, 확대·축소 |
| Enter | 다음 할 일 / 턴 종료 |
| Space · B · F · E | 대기 · 도시 건설 · 쉬기 · 자동 탐험 |
| T · Y · Esc | 연구 창 · 타일 산출량 표시 · 선택 해제 |

매 턴이 끝날 때 브라우저(localStorage)에 자동 저장돼요.

## 파일 구성

- `data.js` — 지형·자원·유닛·건물·지구·기술·정책·세력 데이터
- `engine.js` — 게임 규칙 (지도 생성, 도시, 전투, 연구, 턴 진행, 저장). DOM을 쓰지 않아 Node에서도 돌아가요.
- `ai.js` — 상대 세력과 약탈자 AI
- `ui.js`, `style.css`, `index.html` — 캔버스 렌더링, 입력, 패널, 길잡이
