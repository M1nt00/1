# 테라 헥사 (Terra Hexa)

헥스 타일 위에서 도시를 세우고, 땅을 개발하고, 연구하고, 여러 세력과 경쟁하는 **4X 턴제 전략 게임**이에요.
「문명 6」 같은 본격적인 4X 게임의 핵심 시스템을 간추려, 처음 배우는 사람도 손에 익힐 수 있게 만들었어요.
(특정 게임의 복제가 아니라, 같은 장르의 규칙으로 만든 오리지널 게임이에요. 세력·지도자·불가사의는 모두 창작이에요.)

## 실행

설치나 빌드가 필요 없어요. `index.html`을 브라우저로 열면 바로 시작돼요. PC와 모바일 모두 지원해요.

## 들어 있는 것

- **세력 8개**, 저마다 지도자와 고유 능력 2가지 · 상대 1~5세력 · 난이도 3단계 · 게임 길이(빠름 170턴 / 표준 250턴)
- **6시대 32개 기술** (고대 → 현대)과 **영감**(특정 행동으로 연구 40% 단축)
- 도시 자리 고르기(물가 = 주거), 시민이 타일에서 일하는 구조, 건설자(횟수 소모)
- **지구 5종**(학문·성지·상업·산업·문화)을 타일에 직접 놓고 **인접 보너스** 받기
- **불가사의 9개** — 세계에 하나뿐, 조건에 맞는 타일에 건설
- **종교** — 성지에서 신앙을 모아 창시, 교리 선택, 선교사로 전파
- 문화로 국경 확장·정책 채택, **관광**으로 문화 승리
- 유닛 17종과 금으로 하는 **업그레이드**, 한 타일 한 유닛, 지형 방어, 공성
- 약탈자 야영지, 유적, 외교(전쟁·평화)
- **승리 5가지**: 과학(우주 탐사선) · 문화(관광) · 종교(전도) · 정복(수도 점령) · 점수

게임 안의 **길잡이**가 한 단계씩 안내하고, 도움말의 "다음 단계" 탭에 본격적인 4X 게임으로 넘어갈 때 달라지는 점을 정리해 뒀어요.

## 조작

| 입력 | 동작 |
| --- | --- |
| 클릭 / 탭 | 유닛·도시 선택, 선택한 유닛에게 이동·공격 명령 |
| 우클릭 / 길게 누르기 | 무조건 이동·공격 명령 |
| 드래그, 휠 / 두 손가락 | 지도 이동, 확대·축소 |
| Enter | 다음 할 일 / 턴 종료 |
| Space · B · F · E | 대기 · 도시 건설 · 쉬기 · 자동 탐험 |
| T · Y · Esc | 연구 창 · 타일 산출량 표시 · 선택 해제 |

매 턴이 끝날 때 브라우저(localStorage)에 자동 저장돼요. 효과음은 메뉴에서 끌 수 있어요.

## 파일 구성

- `data.js` — 지형·자원·유닛·건물·지구·불가사의·기술·정책·교리·세력 데이터
- `engine.js` — 게임 규칙 (지도 생성, 도시, 전투, 연구, 종교, 관광, 턴 진행, 저장). DOM을 쓰지 않아 Node에서도 돌아가요.
- `ai.js` — 상대 세력과 약탈자 AI
- `art.js` — 지형·도시·지구·유닛 토큰 그림 (모두 캔버스로 직접 그림, 이미지 파일 없음)
- `sfx.js` — WebAudio로 합성한 효과음
- `ui.js`, `style.css`, `index.html` — 렌더링과 애니메이션, 입력, 패널, 길잡이
